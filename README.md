# 🏥 병원 예약 시스템 (clinic-booking-system)

진료과·의사를 고르고 원하는 날짜와 시간에 진료를 예약하는 웹 서비스입니다.
숙박 예약 플랫폼을 실무에서 개발한 경험을 바탕으로, 예약 도메인을 병원 진료에 맞게 다시 설계하고 있습니다.

## 기술 스택
Next.js 16 (App Router) · React 19 · TypeScript · Mantine · SCSS

## 진행 상황
- [x] 프로젝트 세팅 (Next.js + Mantine + SCSS)
- [ ] 진료과·의사 목록
- [ ] 날짜·시간 선택 후 예약
- [ ] 예약 확인·취소
- [ ] 백엔드 연동 (예정)
- [ ] Vercel 배포

## 개발 방식
Claude Code를 활용해 개발하고, 구조와 기능을 직접 판단하고 검토했습니다.

## 실행 방법
npm install
npm run dev
